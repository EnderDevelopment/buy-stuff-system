# Buy Stuff System

A versatile in-game item purchasing system for FiveM servers.

## Features

- In-game item purchasing
- ESX integration
- Customizable item list
- Money management

## Requirements

- FiveM server
- ESX framework
- MySQL database

## Installation

1. Download the script files.
2. Place the files in your FiveM server's resources directory.
3. Import the database.sql file into your MySQL database.
4. Add `start BuyStuffSystem` to your server.cfg file.

## Usage

- Press the E key to open the buy menu.
- Select an item to purchase.
- The script will handle the money transaction and item delivery.

## Configuration

The script can be configured in the config.lua file. You can customize the database table name, item list, and menu title.
